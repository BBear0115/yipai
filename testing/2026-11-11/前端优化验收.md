# 衣拍前端优化验收

本次前端以手机创作流程为主：上传商品图、选模特、生成、对照检查与保存。保留「我的／开拍／社区」底部导航；中大屏改为顶部导航和宽工作区。

- 首页将上传入口和进行中任务置于首屏附近，历史图片按进行中优先展示；无作品时展示标记清楚的商品原图与效果示例。
- 准备页、生成状态、结果页、创作历史、社区、发布表单及统一弹层已完成；图片可重试加载、切换原图并全屏放大。
- 任务编号写入 hash；刷新只读取原任务。轮询更新历史卡片时保留页面和发布草稿；正在提交时切换页面，任务仍继续且不覆盖新草稿。
- 保留幂等键、单用户单进行中任务、原图重试及服务端带水印成品。未添加后端暂不支持的取消、进度或自动质检。

## 验证

- `node --check mockup/app.js`、`node --check mockup/community.js`：通过。
- `node --test testing/frontend.test.cjs`：13 项通过，覆盖重复提交、幂等重试、任务路由恢复、草稿保留、图片重试和提交中切换页面。
- `python3 -m unittest discover -s backend -v`：17 项通过。
- 浏览器使用隔离模拟预览与记录图片，不调用生图服务。检查 320、390、430、768、1440px；工作台、准备页、结果操作栏和社区均无水平溢出。320px 结果页三个操作完整显示。
- 200% 根字号下检查 390px 工作台、320px 准备/结果/发布页，以及社区全部五种宽度：无水平溢出；准备与结果页的底部留白随操作栏实际高度变化。
- 点选本地测试图、选择模特、提交模拟任务、离开后从历史打开已完成结果、切换原图、放大和下载成功。
- 图片查看器放大至 150% 后画布宽 585px、可视区宽 390px；按 Escape 关闭后焦点回到放大按钮。浏览器前进/后退与任务刷新恢复通过；社区发布、草稿返回恢复及撤回测试作品通过。
