## 使用说明

当前文件是带正确 `.svg` 扩展名的占位图，仅用于检查布局和操作，不处理用户上传图片。若改为真实样例，须同时更新 `studio.js` 中的路径：
- 服装上身效果图
- 不同姿势的模特照
- 不同背景的场景图

## 图片要求

- 当前格式：SVG；真实照片可使用 JPG/PNG/WebP
- 尺寸：建议 600x900 或更高（竖版）
- 文件大小：每张 < 2MB
- 清晰度：高清，无模糊
