# 导出功能集成说明

## 功能概述

为衣拍项目实现了智能文件名导出功能，文件名自动包含任务类型和时间戳。

## 文件名格式

```
衣拍_任务类型_YYYYMMDD_HHMMSS[_序号].jpg
```

### 示例

- **单张图片**: `衣拍_虚拟试穿_20261115_143022.jpg`
- **多张图片**: `衣拍_姿势裂变_20261115_143022_1.jpg`, `衣拍_姿势裂变_20261115_143022_2.jpg`
- **背景替换**: `衣拍_背景替换_海边_20261115_143022.jpg`
- **批量作品**: `衣拍_批量1_虚拟试穿_20261115_143022.jpg`

## 集成位置

### 1. 单张结果页 (`app.js` renderResult)

**位置**: 结果页右侧操作区 "保存图片" 按钮

**功能**: 下载当前查看的单张图片，文件名包含任务类型和时间戳

### 2. 多张结果页 (`app.js` renderResult)

**位置**: 姿势裂变/拍同款结果页 "下载全部 N 张" 按钮

**功能**:
- 优先使用服务器提供的 ZIP 打包下载（如果 `job.downloadAll` 存在）
- 降级方案：逐个下载所有图片（间隔 300ms），每张文件名带序号

### 3. 批量生成结果页 (`batch.js` openBatchResults)

**位置**: 批量生成浮层的两个按钮
- 每个作品卡片的下载按钮
- 底部 "批量下载已完成" 按钮

**功能**:
- 单个作品下载：使用作品的任务类型和时间戳
- 批量下载：下载所有已完成作品的主图，每个文件名格式为 `衣拍_批量N_任务类型_时间戳.jpg`；作品的完整多图结果在单个结果页通过服务端 ZIP 下载。

## 技术实现

### 核心模块

**文件**: `mockup/export.js`

**主要函数**:

1. `generateFilename(job, options)` - 生成智能文件名
   - 自动识别任务类型（虚拟试穿、姿势裂变、背景替换、拍同款）
   - 从 `job.created` 提取时间戳
   - 支持多张图片序号

2. `downloadSingleImage(job, imageUrl, index)` - 下载单张图片
   - 创建隐藏的 `<a>` 标签触发下载
   - 自动清理 DOM

3. `downloadMultipleImages(job, images)` - 批量下载多张图片
   - 缺少服务端 ZIP 时逐个下载，间隔 300ms；无法保证绕过浏览器下载权限
   - 每张图片自动编号

4. `downloadBatchJobs(jobs)` - 批量下载多个作品
   - 过滤已完成的作品
   - 间隔 400ms 逐个下载

### 依赖关系

- **无外部依赖**: 不需要 JSZip 或其他库
- **向后兼容**: 包含降级方案，即使 export.js 未加载也能正常下载（使用旧的文件名格式）

### 加载顺序

在 `index.html` 中，export.js 需要在 app.js 之前加载：

```html
<script src="export.js?v=20261115-export"></script>
<script src="app.js?v=20261115-reference-optional"></script>
```

## 浏览器兼容性

- 使用浏览器原生 `<a download>` 发起保存，实际保存方式和多文件下载权限由浏览器决定。
- 部分浏览器对连续下载有限制；延迟间隔只能分散请求，不能保证绕过权限或下载限制。

## 测试验证

需要验证的导出行为：

- 单张图片下载：文件名包含任务类型和时间戳。
- 多张结果：正常使用已有服务端 ZIP，缺少 `downloadAll` 时才逐张下载。
- 批量作品：只下载已完成作品的主图，文件名区分作品。
- 导出模块未加载时使用旧的保存方式。

测试命令与实际结果以本次提交的核对记录为准；此说明不代表各浏览器均已手动验收。

## 后续优化建议

1. **跨作品 ZIP**: 单个作品已有 `/api/jobs/:id/download.zip`；若需将多个作品合为一个压缩包，可另行设计跨作品导出接口
2. **进度提示**: 批量下载时显示进度条
3. **自定义文件名**: 允许用户在下载前编辑文件名
4. **批量选择**: 允许用户勾选部分图片下载
